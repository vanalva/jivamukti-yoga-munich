10. Breakpointless / Responsive

LUMOS prefers container queries + fluid clamp() over media queries. Webflow fallback breakpoints still exist for edge cases.

When to reach for a media-query override anyway

  • A component needs to fundamentally change structure on small screens (hamburger nav replacing horizontal links).
  • A specific typography trim only looks right above a certain width.
  • An image art direction swap — a horizontal hero image on desktop, a vertical one on mobile.

In every other case, prefer u-grid-autofit, u-flex-horizontal-wrap, or fluid clamp() values.

NeedUse LUMOSCreate custom

Naming rules

Follow LUMOS type_variation_element with underscores. Never use utility-style names, camelCase, or hyphens within a level.

schedule_lehel_row        ← component: schedule, variation: lehel, element: row
schedule_glockenbach_row  ← component: schedule, variation: glockenbach, element: row
teacher_card_photo        ← component: teacher, variation: card, element: photo
price_card_month          ← component: price, variation: card, element: month
nav_studio-badge          ← component: nav, element: studio-badge
footer_studio_address     ← component: footer, variation: studio, element: address

Custom variables

All variables are standard LUMOS. Munich-specific swatches live under existing token names so the rest of the framework works unchanged:

  • --swatch--brand-500: #e68600 — saffron (Munich) replaces Düsseldorf's rust
  • --swatch--light-200: #f1eae0 — cream (Munich) replaces Düsseldorf's beige
  • --swatch--secondary-500: #7f99b5 — Munich slate blue
  • --swatch--tertiary-500: #0d3333 — deep teal (identical to Düsseldorf)
  • --swatch--dark-900: #191a1c — Munich ink
